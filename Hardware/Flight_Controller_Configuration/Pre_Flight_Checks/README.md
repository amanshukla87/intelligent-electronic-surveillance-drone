# Pre-Flight Checks

This folder contains Mission Planner screenshots documenting the pre-flight status checks of the Pixhawk 2.4.8 flight controller before a drone test.

## Documentation

- `pixhawk_preflight_map_view_disarmed.png` — Mission Planner map and telemetry view showing the S550 hexacopter in the disarmed state during pre-flight preparation. The screenshot records the displayed readiness status at that time; it does not indicate that the vehicle was armed or that a flight was completed.
