# Raspberry Pi Setup

This directory contains setup instructions and configuration notes for preparing the Raspberry Pi 4 used in the camera-integrated drone surveillance project.

Setup documentation and files can be added here as they are verified, including:

- Raspberry Pi OS and initial system configuration
- Camera Module V3 setup and verification
- Python environment and required package installation
- OpenCV and YOLO11n deployment dependencies
- Remote access and VNC configuration

> **Note:** Add only commands, versions, and configuration details that have been verified on the project hardware. Model inference results documented elsewhere in this repository were obtained through offline image processing and should not be described as real-time onboard performance.
